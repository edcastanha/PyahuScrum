# Triage Labels — Pyahu Scrum

| Label              | Role                       | Description                                        |
| ------------------ | -------------------------- | -------------------------------------------------- |
| `needs-triage`     | Needs triage               | Nova issue sem classificação inicial                |
| `needs-info`       | Needs more information     | Autor/agent precisa fornecer dados complementares   |
| `ready-for-agent`  | Ready for autonomous work  | Ticket validado, pronto para execução pelo agente    |
| `ready-for-human`  | Needs human attention      | Bloqueio humano identificado durante processamento  |
| `wontfix`          | Declined                   | Issue descartada por decisão explícita               |
